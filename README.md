# Lodgeproof

Lodgeproof checks a retrofit job's paperwork against PAS 2035 before it is lodged, so you find
what would stop it passing audit while there is still time to fix it. You review what it found
and decide what to do.

It runs on your own Windows computer. Your documents never leave it, and it works without an
internet connection.

**This is a beta.** Findings are advisory and the rules are not yet verified against the
published standards. Always check against PAS 2035/2030 and your scheme's guidance.

## Download

[Download the latest Windows installer](https://github.com/fw9c/lodgeproof-download/releases/latest)
(the file ending in `setup.exe`).

You need Windows 10 or 11 (64-bit) and about 200 MB of disk space. Lodgeproof uses under
300 MB of memory while it works.

## Install

1. Open the file you downloaded.
2. Windows may show "Windows protected your PC". The beta is not code-signed yet, so click
   "More info", then "Run anyway".
3. Lodgeproof installs for your Windows user. You do not need an administrator, and there is
   nothing else to install.

## A beta key

The example job works without a key. To check your own jobs you need a beta key: 10 job
checks over 30 days. To request one, email lodgeproof@gmail.com.
