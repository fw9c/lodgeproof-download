A note on the beta

The beta is not yet signed with a code-signing certificate, so Windows SmartScreen may warn that it does not recognise the app. Choose More info, then Run anyway. The download page shows a checksum, so you can confirm it is the file we published.

To check your own jobs you need a beta key: see the beta.

Lodgeproof installs for your Windows user only and does not need an administrator.
